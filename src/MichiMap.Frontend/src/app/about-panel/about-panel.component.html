info_outline About MichiMap

⚠️ This is a portfolio demo. Data may be delayed or incomplete.

MichiMap aggregates real-time Michigan natural event data from public government APIs onto an interactive map. It was built as a full-stack Azure portfolio project.

code View source on GitHub ↗

Data Sources

  • 🌊
    Flood NOAA / NWS — flood warnings, advisories & lakeshore alerts Public Domain — U.S. Government
  • ⚡
    Weather NOAA / NWS — all active Michigan alerts (beach hazards, thunderstorms, wind, winter weather, etc.) Public Domain — U.S. Government
  • 🔥
    Wildfire NIFC WFIGS current incident locations · NASA FIRMS VIIRS satellite detections Public Domain — U.S. Government
  • 🌿
    Controlled Burn Michigan DNR prescribed fire records Public Domain — State of Michigan Open Data
  • 💨
    Air Quality EPA AirNow AQI monitoring stations Public Domain — U.S. Government
  • 🐟
    Fish Atlas Michigan DNR fish stocking and survey records CC BY — Michigan DNR Open Data

Tech Stack

Frontend
Angular 17 · Angular Material · Leaflet.js · Azure Static Web Apps
Backend
ASP.NET Core 8 · Entity Framework Core · Azure SQL · Azure App Service
Ingestion
Azure Functions (timer-triggered, .NET 8 isolated worker)
IaC / CI&CD
Azure Bicep · Azure DevOps Pipelines
